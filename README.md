# 🚀 LayerByLayer Flight Controller v0.1.0

A high-performance, 4-layer custom Flight Controller designed in KiCad 8. Built around the powerful STM32F777 microcontroller, it features an advanced IMU, integrated OSD, and Blackbox logging capabilities, tailored for demanding FPV and autonomous flight applications.

## ✨ Key Features & Hardware Specifications

*   **Microcontroller:** `STM32F777VIT6` (ARM Cortex-M7, 216MHz, 2MB Flash, 512KB RAM)
*   **IMU (Gyro/Accel):** `LSM6DSV320XTR` (Connected via SPI6)
*   **OSD (On-Screen Display):** `MAX7456EUI+` (Analog Video Overlay, SPI4)
*   **Barometer:** `BMP280` (Altitude sensing, I2C1)
*   **Blackbox Flash:** `W25Q128JVS` (16MB/128Mbit SPI Flash for flight data logging, SPI3)
*   **USB Interface:** USB-C 2.0 with `USBLC6-2SC6` ESD protection diode.

---

## ⚡ Power Delivery Network (PDN)

To ensure clean video feeds and stable logic levels, the power delivery is split and filtered:
*   **Main 5V Buck Converter:** Direct LiPo input (VBAT) is stepped down by an `LMR51430Y` synchronous buck converter, providing a highly efficient 5V at up to 3A for the MCU, OSD, and external peripherals (VTX, Camera, GPS).
*   **Clean Video:** A dedicated LC filter is implemented before the VTX/Camera power rail to eliminate electrical noise generated by the ESCs and motors.
*   **3.3V Logic LDO:** An `AP2112K-3.3` linear regulator derives a clean 3.3V from the 5V rail to power the noise-sensitive STM32 MCU, IMU, Baro, and Flash memory.

## 🔌 Connectivity & Interfaces

| Interface | Bus / Pins | Description |
| :--- | :--- | :--- |
| **ESC / Motors** | `M1` - `M4` | 4x Motor Outputs (DShot600 compatible) |
| **Receiver (RX)** | `UART1` | CRSF Protocol (e.g., TBS Crossfire, ExpressLRS) |
| **GPS / Compass** | `UART2` + `I2C1` | GNSS Module connectivity |
| **Video TX (VTX)** | Video Out | 5V, GND, Video Signal (SpeedyBee TX800 VTX support) |
| **Camera** | Video In | 5V, GND, Video Signal (Analog Camera e.g., CADDXFPV) |
| **Debug** | `SWD` | SWCLK / SWDIO pads for ST-Link debugging |

## 🛠️ PCB Stackup (4-Layer)

To ensure signal integrity and controlled impedance for high-speed traces, a standard 4-layer stackup is utilized:
1.  **F.Cu (Top):** Signal & Components
2.  **In1.Cu (Inner 1):** Solid GND Plane
3.  **In2.Cu (Inner 2):** Split Power Planes (3.3V / 5V / VBAT)
4.  **B.Cu (Bottom):** Signal & Minor Components

---

## 📝 Firmware Compatibility

This hardware is architected to be compatible with major open-source flight controller firmware. Custom target definition files are required to map the pins correctly.
*   **Betaflight** (Recommended for FPV)
*   **INAV** (Recommended for Autonomous Flight utilizing the onboard BMP280 and GNSS UART)
